# Momens GitHub Defaults

This repository powers the Momens organization profile and shared community health files.

## Structure

- `profile/README.md`: organization profile shown on GitHub.
- `CONTRIBUTING.md`: default contribution guidance.
- `CODE_OF_CONDUCT.md`: participation expectations.
- `SECURITY.md`: vulnerability reporting guidance.
- `SUPPORT.md`: support routing.
- `.github/ISSUE_TEMPLATE/`: default issue forms.
- `.github/pull_request_template.md`: default pull request checklist.

## Updating

Keep this repository general. Repo-specific setup, commands, architecture notes, and ownership rules should live in each product repository.
