# Momens

Momens is a Product Memory platform for maker teams.

Product work leaves context across Slack, Notion, Linear, Figma, customer feedback, documents, and code. Momens turns those fragments into durable, source-backed memory so teams can understand what happened, why a decision was made, and what needs attention next.

## What We Build

- Product Memory for decisions, risks, blockers, open questions, tasks, and project context.
- Minsu, a product agent that retrieves context with evidence instead of asking teams to rebuild history by hand.
- Source pipelines that capture collaboration signals before they disappear into tool history.
- Feedback loops that connect decisions to actions, launches, customer response, and later learning.

## Principles

- Every answer needs a source.
- Human review stays in the loop.
- Product context should be reusable, not just archived.
- Dense work surfaces should stay calm, precise, and traceable.
