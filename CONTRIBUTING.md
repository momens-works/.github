# Contributing to Momens

Thanks for helping improve Momens.

## Before You Start

- Read the affected repository's README and docs first.
- Check existing issues or pull requests for related context.
- Keep the change scoped to the problem being solved.
- Ask a maintainer before changing public contracts, data models, migrations, deployment behavior, or security-sensitive flows.

## Pull Requests

Good pull requests include:

- A short summary of what changed and why.
- Tests, screenshots, logs, or manual verification notes where relevant.
- Documentation updates when behavior, setup, or operational expectations changed.
- Clear notes for any follow-up work that is intentionally left out.

## Review Standards

We value changes that are:

- Source-backed and easy to verify.
- Small enough to review with confidence.
- Explicit about product, API, data, and infrastructure boundaries.
- Careful with permissions, credentials, user data, and production behavior.
