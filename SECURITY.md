# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub private vulnerability reporting on the affected repository when it is available. If that is not available, contact a Momens maintainer directly with:

- The affected repository, service, or domain.
- A clear reproduction path.
- The potential impact.
- Any logs, screenshots, or request examples that help verify the issue.

We will acknowledge valid reports as quickly as possible and coordinate a fix before public disclosure.

## Supported Scope

Security reports are accepted for active Momens repositories, production services, deployment configuration, authentication flows, source integrations, data handling, and dependency supply chain issues.
